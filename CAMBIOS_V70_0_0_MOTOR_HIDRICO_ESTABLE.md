# LA MAGDALENA OS v70.0.0 — Motor Hídrico Estable

- Mantiene una única fuente canónica para las 13 válvulas.
- Conserva el último cálculo válido mientras Supabase, clima o satélite terminan de cargar.
- Bloquea cambios mayores a 25 puntos si no existe nueva evidencia (riego, lluvia, muestra o satélite).
- Registra localmente hasta 500 cambios auditables por válvula.
- Cada resultado incluye revisión, hora, motivo, evidencia y estado de estabilización.
- No modifica ni elimina registros de Supabase.
