# LA MAGDALENA OS v66.0.0 — Datos hídricos unificados

- Un único snapshot canónico por válvula generado por el motor de Inteligencia Hídrica.
- Inicio Premium, Centro Inteligente e Historial de Riegos consumen exactamente el mismo porcentaje, decisión, lámina, volumen y confianza.
- El snapshot se invalida y reconstruye después de cada recarga de Supabase.
- La pestaña Riego muestra las 13 válvulas antes del historial, sin recalcular valores.
- Diseño responsive para evitar textos, cifras y tarjetas superpuestas.
- No incluye migraciones SQL ni elimina registros.
