# LA MAGDALENA OS 36.8 — Motor de riego operativo

1. Ejecutar `00_SQL_ACTIVAR_CARGA_REAL_SUPABASE.sql` una sola vez en Supabase.
2. Ejecutar `bash ./00_INSTALAR_Y_ABRIR_V36_8.command`.
3. En Xcode presionar Command + R.
4. Abrir **Inteligencia hídrica → Preparar lotes**.
5. Para cada lote: perfil, densidad aparente, muestras 0–30 y 30–60, y riegos/lluvias posteriores.

Las instrucciones son orientativas hasta completar densidad aparente, capacidad de campo y punto de marchitez y contrastarlas con observaciones de campo.
