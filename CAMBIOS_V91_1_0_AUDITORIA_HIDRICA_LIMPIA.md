# LA MAGDALENA OS v91.1.0 — Auditoría hídrica limpia

- El motor hídrico canónico no cambia.
- El historial del porcentaje ahora registra sólo cambios reales de porcentaje o decisión.
- La vista oculta eventos sin variación (por ejemplo 0% → 0%) y rebotes legados sin evidencia hídrica fuerte.
- Cada cambio visible se clasifica como dato observado, dato remoto o recálculo del balance.
- El historial técnico original permanece en localStorage; no se borra información previa.
- El historial integrado conserva muestreos, riegos, satélite y observaciones.
