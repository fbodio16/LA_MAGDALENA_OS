# LA MAGDALENA OS 13.0.0 · Gestión Integral de Campaña

## Incorporado
- Alta y edición de campañas agrícolas.
- Objetivos de producción e ingresos.
- Asociación de lotes, cortes, ventas y viajes a una campaña.
- Resumen consolidado de superficie, rollos, toneladas, ingresos, costos, cobranzas y margen.
- Comparación histórica entre campañas.
- Vista de rendimiento por lote.
- Migración SQL segura con RLS e índices.
