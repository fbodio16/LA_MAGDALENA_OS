# LA MAGDALENA OS v84.0.0

## Gemelo Digital Integral integrado al Centro de Riego

- Clic directo sobre los marcadores de las 13 válvulas abre el Gemelo Digital Integral.
- Clic sobre las tarjetas/resumen del mapa hídrico abre el mismo expediente agronómico.
- El botón "Abrir detalle completo" conserva el detalle hídrico específico.
- El Gemelo usa las filas canónicas del Motor Hídrico protegido para que el porcentaje de agua coincida con Inicio Premium.
- Si no existe análisis nutricional, se muestra "Sin análisis nutricional" y no se infiere ausencia de limitantes.
- Mantiene laboratorio, nutrición, satélite, clima, producción, fertilización y línea de tiempo integrados.
- No modifica hydric-state.js, hydric-intelligence/index.js ni premium-home/index.js.
