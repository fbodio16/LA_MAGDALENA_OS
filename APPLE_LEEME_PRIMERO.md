# LA MAGDALENA OS 36 · Apple

Esta edición usa la misma aplicación web comprobada con Supabase y la envuelve con Capacitor para iPhone, iPad y Mac.

## Primera instalación

1. Abrir Terminal dentro de esta carpeta.
2. Ejecutar `bash ./01_CREAR_APP_APPLE.command`.
3. Esperar a que Xcode se abra.
4. Elegir un simulador y ejecutar con `⌘R`.

## Después de modificar la web

Ejecutar `bash ./02_SINCRONIZAR_APP_APPLE.command` para copiar los cambios y abrir Xcode.

## Proyecto web

La aplicación productiva está en `apps/web`. La carpeta `apps/mobile-expo-legacy` se conserva únicamente como referencia histórica; no es necesaria para la app de Xcode.
