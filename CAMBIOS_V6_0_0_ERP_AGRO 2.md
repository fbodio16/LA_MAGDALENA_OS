# LA MAGDALENA OS 6.0.0 · ERP Agropecuario

## Cambios verificables

- Nuevo **Centro operativo** accesible desde el menú principal.
- Resultado consolidado de alfalfa, transporte y movimientos financieros.
- Plan automático de prioridades: cortes demorados, NDVI bajo, órdenes T100 y stock disponible.
- Accesos directos a Alfalfa, Transporte, Precisión, Riego, Clientes y Administración.
- Exportación de un resumen operativo a CSV.
- Nueva hoja de estilos específica para la vista operativa.
- Caché PWA actualizado a `lmos-web-v600-erp-agro`.
- Identificación visual de versión 6.0.0.

## Instalación

Ejecutar `INSTALAR_EN_GITHUB.command`. El instalador compara archivos, copia la versión y muestra el listado real de cambios antes de abrir GitHub Desktop.
