# LA MAGDALENA OS 25.0.0 — CRM Profesional

## Incluye
- Dashboard comercial
- Alta y edición de clientes
- Datos fiscales y comerciales
- Ficha 360
- Contactos y establecimientos
- Pipeline de oportunidades
- Actividades de seguimiento
- Búsqueda rápida
- Seguridad multiempresa con RLS

## Instalación
1. Ejecutar `supabase/028_crm_profesional_v25.sql` en Supabase SQL Editor.
2. Abrir la web local con `ABRIR_WEB_LOCAL.command`.
3. Ingresar al menú **CRM Profesional**.
