# LA MAGDALENA OS v75 — Modo Decisión

Una señal de estrés no equivale automáticamente a una orden de riego.

La aplicación marca una válvula como **DECISIÓN HABILITADA** solamente cuando:

- el sector tiene datos mínimos completos;
- el balance hídrico está calibrado, no estimado;
- la confianza del cálculo es al menos 80%;
- la muestra gravimétrica tiene 21 días o menos;
- existe ET₀ válida;
- si la recomendación es regar, existe una lámina positiva;
- si la recomendación es regar, hay tasa/caudal calibrado y duración calculable;
- el valor no está siendo conservado temporalmente por el estabilizador.

Si alguna condición falla, el porcentaje y la señal siguen visibles, pero la interfaz muestra **VERIFICAR ANTES DE ACTUAR** y enumera qué dato falta. Esto evita convertir un cálculo incompleto en una decisión operativa.

## Protocolo de uso

1. Revisar primero las válvulas rojas/amarillas.
2. Confirmar que la válvula diga DECISIÓN HABILITADA.
3. Revisar lámina, volumen y tiempo.
4. Registrar el riego al terminar.
5. Volver a medir suelo en 24–48 h cuando el sistema lo indique.
