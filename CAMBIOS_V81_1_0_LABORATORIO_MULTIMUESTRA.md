# LA MAGDALENA OS v81.1.0

## Laboratorio Inteligente Multimuestra

- Un único Excel puede contener múltiples muestras o válvulas.
- Detección de formatos por filas o por columnas.
- Asociación previa de cada muestra con lote/válvula.
- Aprendizaje local de equivalencias de nombres para futuras importaciones.
- Un solo archivo original archivado; un registro de análisis por muestra.
- Trazabilidad por lote, etiqueta original, hoja, posición y lote de importación.
- Detección de duplicado por SHA-256 del archivo completo.
- Los resultados importados quedan pendientes de revisión.
- El Motor Hídrico protegido no se modifica ni recibe efectos automáticos.
